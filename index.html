How to run

This is a pure HTML / CSS / JavaScript submission — no Node.js, npm packages or build tools are required.

  1. Open the Web-Practical-Programs folder in Visual Studio Code.
  2. Install the Live Server extension if it isn't already installed.
  3. Right-click index.html and choose Open with Live Server.
  4. Use the Dashboard navigation to browse the HTML, CSS and JavaScript sections.
